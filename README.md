# Shresh - The Future 🤖

A prototype AI Chatbot built using **Flask** and **Hugging Face DialoGPT** model.

## 🚀 Features
- Interactive chat interface (HTML + CSS + JS)
- Flask backend using Hugging Face Transformers
- Real-time AI responses

## 🧰 Requirements
- Python 3.8+
- Flask
- Transformers
- Torch

```bash
git clone https://github.com/YOUR_USERNAME/chatbot-project.git
cd chatbot-project
